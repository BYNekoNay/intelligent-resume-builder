## 7. 关键代码骨架

### 7.1 实体

```java
// server/src/main/java/com/intelligentresume/auth/domain/User.java
package com.intelligentresume.auth.domain;

import com.intelligentresume.common.domain.BaseEntity;
import jakarta.persistence.*;
import org.hibernate.annotations.SQLRestriction;

import java.time.LocalDateTime;

@Entity
@Table(name = "user")
@SQLRestriction("deleted_at IS NULL")
public class User extends BaseEntity {

    @Column(name = "username", nullable = false, length = 64, unique = true)
    private String username;

    @Column(name = "email", nullable = false, length = 128, unique = true)
    private String email;

    @Column(name = "password_hash", nullable = false, length = 255)
    private String passwordHash;

    @Enumerated(EnumType.STRING)
    @Column(name = "status", nullable = false)
    private UserStatus status = UserStatus.ACTIVE;

    @Column(name = "deleted_at")
    private LocalDateTime deletedAt;

    // getters / setters
}

enum UserStatus { ACTIVE, DISABLED }
```

```java
// server/src/main/java/com/intelligentresume/auth/domain/AuthSession.java
package com.intelligentresume.auth.domain;

import jakarta.persistence.*;
import java.time.LocalDateTime;

@Entity
@Table(name = "auth_session")
public class AuthSession {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "user_id", nullable = false)
    private Long userId;

    @Column(name = "token_family_id", nullable = false, length = 64)
    private String tokenFamilyId;

    @Column(name = "refresh_token_hash", nullable = false, length = 255, unique = true)
    private String refreshTokenHash;

    @Column(name = "expires_at", nullable = false)
    private LocalDateTime expiresAt;

    @Column(name = "revoked_at")
    private LocalDateTime revokedAt;

    @Column(name = "replaced_by_session_id")
    private Long replacedBySessionId;

    @Column(name = "last_used_at")
    private LocalDateTime lastUsedAt;

    @Column(name = "device_label", length = 128)
    private String deviceLabel;

    @Column(name = "created_at", nullable = false, updatable = false)
    private LocalDateTime createdAt;

    // getters / setters
}
```

> AuthSession 不继承 BaseEntity(无 updated_at 字段,见 V1 DDL)。

### 7.3 DTO

```java
public record RegisterRequest(
    @NotBlank @Size(min = 3, max = 64) String username,
    @NotBlank @Email @Size(max = 128) String email,
    @NotBlank @Size(min = 8, max = 64) String password

public record AuthResponse(

    String refreshToken,    // 仅在 Set-Cookie 之外,API 调试用;生产可省略
```

### 7.4 Service 关键方法签名

```java
@Service
public class AuthService {

    public UserInfo register(RegisterRequest request);
    public AuthResponse login(LoginRequest request, String deviceLabel);
    public AuthResponse refresh(String refreshTokenCookieValue);
    public void logout(String refreshTokenCookieValue, boolean allSessions);
    public UserInfo me(Long currentUserId);
}
```

**关键不变量**(必须实现,见 T00 §3.2):

1. `password_hash` 使用 BCrypt(`BCryptPasswordEncoder`),cost ≥ 10
2. **不保存明文刷新令牌**;数据库只存 `refreshTokenHash = SHA-256(token)`
3. 登录成功时生成新的 `token_family_id`(UUID),并写入 `auth_session`
4. 刷新时:查询 session → 校验未撤销 + 未过期 → **校验旧 token 与 hash 匹配** → 撤销旧 session → 创建新 session(`replaced_by_session_id` 指向旧 session)→ 返回新 token 对
5. **检测到旧令牌复用**:撤销整个 `token_family_id` 的所有 session,返回 `40101`
6. 不在日志或异常消息中打印 token、密码、邮箱以外的敏感信息

### 7.5 TokenService 关键方法

```java
@Service
public class TokenService {

    public String generateAccessToken(Long userId, String username);
    public String generateRefreshToken();   // 返回随机字符串,服务端仅存 hash
    public Long parseAccessTokenUserId(String token);
    public String hashRefreshToken(String token); // SHA-256
}
```

### 7.6 JwtAuthenticationFilter 关键行为

- 从 `Authorization: Bearer <token>` 读取 access token
- 校验失败不抛异常,继续到下一过滤器(由 Spring Security 决定是否放行)
- 成功时填充 `SecurityContextHolder` 为 `UsernamePasswordAuthenticationToken`
- 公开白名单(不需要 token):`/api/auth/register`、`/api/auth/login`、`/api/auth/refresh`、`/api/system/health`

### 7.7 RateLimitFilter 关键行为

- 基于 ConcurrentHashMap 维护每个 IP 的令牌桶(简化版,不引入 Bucket4j)
- 命中规则:返回 `42901`(使用 `ErrorCode.RATE_LIMITED`)
- 三类规则:`login-per-ip-per-minute`、`register-per-ip-per-minute`、`refresh-per-ip-per-minute`

### 7.8 Controller 路由

| 方法 | 路径 | 说明 | 是否需鉴权 |
| --- | --- | --- | --- |
| POST | `/api/auth/register` | 注册,返回 `UserInfo` | 否 |
| POST | `/api/auth/login` | 登录,返回 `AuthResponse`,Set-Cookie 写入 refresh token | 否 |
| POST | `/api/auth/refresh` | 刷新,读 Cookie,Set-Cookie 写新 token | 否 |
| POST | `/api/auth/logout` | 退出,撤销当前 session;`?allSessions=true` 撤销全部 | 是 |
| GET | `/api/auth/me` | 当前用户信息 | 是 |
| GET | `/api/ai/consent` | (本卡不实现,T06 实现) | - |
| POST | `/api/ai/consent` | (本卡不实现) | - |
| DELETE | `/api/ai/consent` | (本卡不实现) | - |

> `/api/auth/refresh` 与 `/api/auth/logout` 的请求与响应必须与 `05 §2.3/§2.4` 一致。

### 7.9 SecurityConfig 关键行为

- `csrf().disable()`(API 服务,使用 JWT)
- `sessionManagement().sessionCreationPolicy(STATELESS)`
- `/api/auth/**` 与 `/api/system/health` permitAll
- 其他 `/api/**` 需要 `.authenticated()`
- 注册自定义 filter:`JwtAuthenticationFilter` 在 `UsernamePasswordAuthenticationFilter` 之前;`RateLimitFilter` 在最前

```bash
# 注册
curl -i -X POST http://localhost:8080/api/auth/register \
    -H "Content-Type: application/json" \
    -d '{"username":"alice","email":"alice@example.com","password":"correcthorse"}'
# 期望: HTTP 200, body.code=0

# 登录
curl -i -c cookies.txt -X POST http://localhost:8080/api/auth/login \
    -H "Content-Type: application/json" \
    -d '{"username":"alice","password":"correcthorse"}'
# 期望: Set-Cookie: irt_refresh=...; HttpOnly; SameSite=Lax

# 获取当前用户
curl http://localhost:8080/api/auth/me -b cookies.txt \
    -H "Authorization: Bearer <accessToken>"
# 期望: code=0, data.username=alice

# 刷新
curl -i -b cookies.txt -c cookies.txt -X POST http://localhost:8080/api/auth/refresh
# 期望: 新的 Set-Cookie, 旧 cookie 被替换

# 退出
curl -i -b cookies.txt -X POST http://localhost:8080/api/auth/logout
# 期望: code=0
```
