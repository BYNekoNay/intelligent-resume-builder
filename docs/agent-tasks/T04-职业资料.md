## 7. 关键代码骨架

### 7.1 实体

```java
@Entity
@Table(name = "career_material")
@SQLRestriction("deleted_at IS NULL")
public class CareerMaterial extends BaseEntity {

    @Column(name = "user_id", nullable = false)
    private Long userId;

    @Enumerated(EnumType.STRING)
    @Column(name = "material_type", nullable = false, length = 32)
    private MaterialType materialType;

    @Column(name = "title", nullable = false, length = 128)
    private String title;

    @JdbcTypeCode(SqlTypes.JSON)
    @Column(name = "content_json", nullable = false, columnDefinition = "json")
    private Map<String, Object> contentJson;

    @Column(name = "source_text", columnDefinition = "TEXT")
    private String sourceText;

    @Enumerated(EnumType.STRING)
    @Column(name = "usage_preference", nullable = false, length = 32)
    private UsagePreference usagePreference = UsagePreference.NORMAL;

    @Column(name = "deleted_at")
    private LocalDateTime deletedAt;

    // getters / setters
}

enum MaterialType {
    WORK_EXPERIENCE,
    PROJECT_EXPERIENCE,
    SKILL,
    EDUCATION,
    CERTIFICATE,
    HIGHLIGHT
}

enum UsagePreference {
    NORMAL, PREFERRED, EXCLUDED
}
```

### 7.2 Repository

```java
public interface CareerMaterialRepository extends JpaRepository<CareerMaterial, Long> {
```

### 7.3 DTO

```java
public record CreateCareerMaterialRequest(
    @NotNull MaterialType materialType,
    @NotBlank @Size(max = 128) String title,
    @NotNull Map<String, Object> contentJson,
    @Size(max = 65535) String sourceText,
    UsagePreference usagePreference  // 默认 NORMAL
) {}

public record UpdateCareerMaterialRequest(
    @Size(max = 128) String title,
    Map<String, Object> contentJson,
    @Size(max = 65535) String sourceText,
    UsagePreference usagePreference
) {}

public record CareerMaterialSummary(
    Long id,
    MaterialType materialType,
    String title,
    UsagePreference usagePreference,
    LocalDateTime updatedAt
) {}

public record CareerMaterialDetail(
    Long id,
    MaterialType materialType,
    String title,
    Map<String, Object> contentJson,
    String sourceText,
    UsagePreference usagePreference,
    LocalDateTime createdAt,
    LocalDateTime updatedAt
) {}
```

### 7.4 Service 关键方法

```java
@Service
public class CareerMaterialService {
    public CareerMaterialDetail create(CreateCareerMaterialRequest req, Long userId);
    public List<CareerMaterialSummary> list(Long userId, MaterialType filter /* nullable */);
    public CareerMaterialDetail get(Long id, Long userId);
    public CareerMaterialDetail update(Long id, UpdateCareerMaterialRequest req, Long userId);
    public void softDelete(Long id, Long userId);

    // 实现要点:
    // 1. 所有方法都通过 userId 过滤,跨用户返回 NOT_FOUND
    // 2. softDelete 设置 deleted_at;数据被 resume_material_reference 引用时不物理删除
    // 3. update 允许部分字段,只更新非 null 字段
}
```

### 7.5 Controller 路由

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/career-materials` | 创建 |
| GET | `/api/career-materials?materialType=PROJECT_EXPERIENCE` | 列表(可选类型过滤) |
| GET | `/api/career-materials/{id}` | 详情 |
| PUT | `/api/career-materials/{id}` | 更新 |
| DELETE | `/api/career-materials/{id}` | 软删 |

### 7.6 关键不变量

- **`userId` 一律从 `@CurrentUserId` 取**,不接受请求体传入
- **类型过滤**:MaterialType 必须是枚举值,否则 `VALIDATION(40001)`
- **contentJson 字节数**:`ObjectMapper.writeValueAsBytes(...).length ≤ app.career-material.content-json.max-bytes`
- **软删可追溯**:被 `resume_material_reference.source_snapshot_json` 引用的资料,删除后历史快照仍可读
- **不允许修改 `userId`**:`update` 不接受 userId 字段
