### 5.2 `server/src/main/resources/application.yml`(修改)

在 `spring:` 下追加以下键(保持原有结构):

```yaml
spring:
  datasource:
    url: jdbc:mysql://${MYSQL_HOST:127.0.0.1}:${MYSQL_PORT:3306}/${MYSQL_DATABASE:intelligent_resume}?useUnicode=true&characterEncoding=utf8&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai
    username: ${MYSQL_USER:resume_app}
    password: ${MYSQL_PASSWORD:resume_app_dev}
    driver-class-name: com.mysql.cj.jdbc.Driver
  jpa:
    hibernate:
      ddl-auto: validate
    open-in-view: false
    properties:
      hibernate:
        dialect: org.hibernate.dialect.MySQLDialect
        jdbc.time_zone: Asia/Shanghai
  flyway:
    enabled: true
    baseline-on-migrate: false
    locations: classpath:db/migration
```

> **不允许把 `ddl-auto` 设为 `update` 或 `create`**。本项目只允许 Flyway 管理 schema。`validate` 会在实体与表不匹配时启动失败。

## 7. 关键代码骨架

### 7.1 实体公共基类

```java
// server/src/main/java/com/intelligentresume/common/domain/BaseEntity.java
package com.intelligentresume.common.domain;

import jakarta.persistence.*;
import org.hibernate.annotations.SQLRestriction;
import org.springframework.data.annotation.CreatedDate;
import org.springframework.data.annotation.LastModifiedDate;
import org.springframework.data.jpa.domain.support.AuditingEntityListener;

import java.time.LocalDateTime;

@MappedSuperclass
@EntityListeners(AuditingEntityListener.class)
public abstract class BaseEntity {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @CreatedDate
    @Column(name = "created_at", nullable = false, updatable = false)
    private LocalDateTime createdAt;

    @LastModifiedDate
    @Column(name = "updated_at", nullable = false)
    private LocalDateTime updatedAt;

    // getters / setters
    public Long getId() { return id; }
    public LocalDateTime getCreatedAt() { return createdAt; }
    public LocalDateTime getUpdatedAt() { return updatedAt; }
}
```

> 本卡**不需要**给 BaseEntity 加 `deletedAt` 字段(由各实体自行决定);也不需要启用 `@EnableJpaAuditing`(留待 T03 引入)。

### 7.2 不要在本卡创建业务实体

> 本卡**不创建**任何业务实体的 JPA Entity 类(留给 T02–T10)。如果加了,会与后续 Tnn 冲突。
>
> 验证 `ddl-auto: validate` 时,**Flyway 只对已建表做 schema 校验**,不验证实体类。

### 7.3 软删约定(文档化,本卡不实现)

- 实体类按需添加 `@SQLRestriction("deleted_at IS NULL")`
- Repository 不需要过滤 deleted(由 Hibernate 自动追加)
- 软删用 `UPDATE ... SET deleted_at = NOW()`,不调用 `delete()`

实现要点:
