## 7. 关键代码骨架

### 7.1 实体

```java
// Resume.java
@Entity
@Table(name = "resume")
@SQLRestriction("deleted_at IS NULL")
public class Resume extends BaseEntity {

    @Column(name = "user_id", nullable = false)
    private Long userId;

    @Column(name = "title", nullable = false, length = 128)
    private String title;

    @JdbcTypeCode(SqlTypes.JSON)
    @Column(name = "base_resume_json", nullable = false, columnDefinition = "json")
    private Map<String, Object> baseResumeJson;

    @Column(name = "current_version_id")
    private Long currentVersionId;

    @Column(name = "deleted_at")
    private LocalDateTime deletedAt;

    // getters / setters
}
```

```java
// ResumeVersion.java
@Entity
@Table(name = "resume_version")
public class ResumeVersion {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "resume_id", nullable = false)
    private Long resumeId;

    @Column(name = "version_no", nullable = false)
    private Integer versionNo;

    @Enumerated(EnumType.STRING)
    @Column(name = "source_type", nullable = false, length = 32)
    private ResumeSourceType sourceType;

    @JdbcTypeCode(SqlTypes.JSON)
    @Column(name = "resume_json", nullable = false, columnDefinition = "json")
    private Map<String, Object> resumeJson;

    @Column(name = "optimization_summary", columnDefinition = "TEXT")
    private String optimizationSummary;

    @JdbcTypeCode(SqlTypes.JSON)
    @Column(name = "generation_context_json", columnDefinition = "json")
    private Map<String, Object> generationContextJson;

    @Column(name = "created_at", nullable = false, updatable = false)
    private LocalDateTime createdAt;

    // getters / setters
}

enum ResumeSourceType {
    MANUAL, AI_OPTIMIZED, JD_CUSTOMIZED, MATERIAL_CUSTOMIZED
}
```

### 7.4 JsonResumeValidator 关键方法

```java
@Component
public class JsonResumeValidator {

    public void validate(Map<String, Object> resumeJson);

    // 实现要点:
    // 1. resumeJson 不能为空
    // 2. 顶层必须有 "basics"
    // 3. 序列化后字节数 ≤ app.resume.json-schema.max-bytes
    // 4. 顶层 key 必须在 allow-sections 中,否则抛 BusinessException(VALIDATION)
    // 5. 不递归校验内部结构(JSON Resume 标准允许扩展)
}
```

### 7.6 Controller 路由

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/resumes` | 创建 |
| GET | `/api/resumes` | 列表 |
| GET | `/api/resumes/{id}` | 详情 |
| PUT | `/api/resumes/{id}` | 更新(可只更新 title 或 baseResumeJson) |
| DELETE | `/api/resumes/{id}` | 软删 |
| POST | `/api/resumes/{id}/versions` | 保存版本(自动分配 versionNo) |
| GET | `/api/resumes/{id}/versions` | 版本历史 |
| GET | `/api/resume-versions/{id}` | 版本详情 |
| PATCH | `/api/resumes/{id}/current-version` | 切换当前版本,Body: `{ "versionId": 100 }` |

### 7.7 关键不变量

- **跨用户访问**:Repository 自定义方法必须带 `userId` 条件;Controller 不接受请求体中的 `userId`
- **版本号唯一**:`UNIQUE(resume_id, version_no)` 已在 V1 创建;Service 必须原子获取下一个版本号
- **历史版本不可修改**:本卡不提供 `PUT /api/resume-versions/{id}`,只能 `POST` 新版本
- **软删**:`DELETE /api/resumes/{id}` 设置 `deleted_at`;版本不删除,以保留历史快照
- **无效 JSON Resume**:Validator 抛 `BusinessException(VALIDATION)`
