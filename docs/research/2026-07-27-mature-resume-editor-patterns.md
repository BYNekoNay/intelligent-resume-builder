# 成熟简历编辑器模式补充调研（官方一手资料）

调研日期：2026-07-27。本文补充现有竞品调研，范围仅限产品官网可公开核验的内容；不把营销承诺推导为未被证实的交互细节，也不使用第三方测评。

## 可确认的共同模式

| 产品 | 官方证据 | 可借鉴的交互模式 |
| --- | --- | --- |
| [Resume.io Resume Builder](https://resume.io/resume-builder) | 官方入口将简历生成器、模板、示例、ATS Scorer 与 AI Builder 作为独立入口；模板按 ATS、Modern、Professional、Simple 等目的分组。 | 默认填写路径不混入模板选择；“设计与高级”应展示缩略图、名称和适用场景，并按求职目的而不是纯颜色分组。 |
| [Novoresume Resume Builder](https://novoresume.com/resume-builder) | 官方页面的流程是选择模板、跟随内建提示、填写工作经历与其他经验、下载；同时按一页、两页、学生、专业人士等任务分类模板。 | 章节填写优先，字段级提示补充在当下，不用整份简历重写打断用户；预计页数和溢出提示放在预览或设计层。 |
| [Enhancv Resume Builder](https://enhancv.com/resume-builder/) | 官方站将 AI Resume Builder、Resume Checker、Templates 和 Examples 划分为独立工具；模板链接以 `template` 和 `color` 作为独立参数。 | 保持章节编辑为主工作区，AI、检查、模板作为按需入口；模板/配色变化需即时反映在预览，但不应占据填写画布。 |
| [FlowCV Resume Builder](https://flowcv.com/resume-builder) | 官方流程区列出“Choose a template”“Customize layout & design”“Download unlimited PDFs”，并说明可保存自定义模板。 | 把模板、内容、版式和输出呈现为可回跳的阶段，支持当前“内容编辑 → 设计与高级 → 全页预览 → 创建版本”的路径。 |
| [Reactive Resume 官方仓库](https://github.com/AmruthPillai/Reactive-Resume) | 维护方 README 列出实时预览、区块拖拽排序、模板、颜色/字体/间距设置、多语言及 JSON 导出。 | 结构化区块排序必须同时保留键盘上移/下移；内容与样式分离；多语言和可访问性不是桌面端的附属功能。 |

## 对当前编辑器的判断

当前 `ResumeEditorView.vue` 已经与上述共识基本对齐：左侧章节完成度、单章节内容编辑、独立的“设计与高级”、按需进入的全页 A4 预览，以及本地草稿和显式“保存新版本”。这比恢复为常驻三栏预览更接近“填写优先”的主路径。

下一轮应优先收紧，而不是增加并行面板：

1. **保留全页预览。** 桌面预览不能重新塞回右轨。预览工具栏只保留返回编辑、页数/溢出和保存新版本；模板与字段操作继续留在其各自模式。
2. **把设计视图做成真正的次级工作区。** 设计项按“适用场景 → 模板 → 密度/字体/留白”组织，模板卡显示缩略、名称和用途。关闭后必须回到原章节和滚动位置。
3. **把完成度转换成下一步。** 章节导航展示条目数与一个可行动的缺失提示；“下一部分”只建议，不锁死跳转。空章节应提供一个直接的新增动作和一句写作提示。
4. **明确两种保存语义。** 600 ms 防抖的本地草稿应显示为“本机草稿已保存”；服务器按钮始终称为“保存新版本”。不要把本地恢复误表述成已创建版本。
5. **继续控制 AI 的存在感。** AI 仅出现在摘要、职责、成果和项目说明等可编辑文字旁；候选须同时显示原文/建议/采纳，且不自动写回、不虚构事实。
6. **移动端保持单一模式。** 小屏优先章节导航和当前区块；进入预览后完全替换编辑页，返回时恢复章节、焦点和滚动。拖拽外必须保留上移/下移按钮。

## 证据边界

上述公开官方页面没有提供足以核验的登录后版本历史、草稿恢复或移动端编辑手势细节。因此，本项目的“本地草稿 + 显式创建版本”“全页移动预览”“键盘排序替代”等决定，应以本项目的安全性、可访问性和 E2E/真实浏览器验收为依据，不能声称为任一竞品的已证实实现。

## 推荐验收任务

用 5 名目标用户验证三项任务：新增一段经历、切换一个适用模板并检查页数、从预览返回后继续填写再保存新版本。记录完成率、完成时间、误操作次数，以及用户能否清楚区分“草稿已保存”和“新版本已创建”。
