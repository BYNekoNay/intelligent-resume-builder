# Windows 桌面版方向

记录日期：2026-10-20
状态：业务方向已确认，需求基线已记录；技术架构与实现暂缓

## 背景

计划重新构建智历。先收口业务流程与首版范围，再评估桌面端架构和实现，避免技术方案先于产品约束。

## 已确认方向

- 首发平台为 Windows，用户通过一个安装包安装并启动应用；不要求用户自行安装 Java、MySQL、Node.js 或配置服务器。
- 主要业务与用户数据保存在本机。离线时可使用核心简历工作流；本地数据存储空间可接受。
- 应用不内置 AI 模型，也不由产品方代配模型账号或 API Key。
- 应用提供 AI API 接入设置，由用户自行提供兼容的大模型接口、模型名及凭据。调用云端接口需要网络；本机模型仅在用户自行部署并配置本地接口时可用。
- 当前桌面技术候选为 Tauri + Vue 前端、本地业务服务与 SQLite。业务服务优先建议沿用 Java，以减少与在线版之间的业务规则漂移；最终技术选择仍待技术方案阶段评估。

## 暂缓事项

业务流程与功能范围已整理到 [`docs/plans/2026-10-20-001-feat-windows-offline-career-workspace-plan.md`](../plans/2026-10-20-001-feat-windows-offline-career-workspace-plan.md)。需求规格已补充并确认 AI 配置与失败降级、申请状态历史及应用关闭时的本地通知、导入冲突与原子合并、备份快照替换和安全备份等规则。具体技术架构、AI API 兼容协议、凭据保护、Windows 通知实现和导出格式版本策略留待技术阶段评估。候选技术栈不视为最终架构决策，桌面端重建仍未启动。
