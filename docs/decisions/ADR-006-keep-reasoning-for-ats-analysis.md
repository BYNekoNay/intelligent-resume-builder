# ADR-006: 保留 ATS_ANALYSIS 的模型推理（本轮实验未能回答该问题）

## Status: Accepted (2026-09-25)

## Background

ADR-005 对 `JOB_GENERATION` 关闭推理后，该任务从 **477s 降到 7s**。自然要问：**判断类任务（ATS 语义分析）是否也该关闭？**

驱动这个问题的实测事实：
- 生产 ATS 分析单次 **212 / 290 / 405s**（任务级，含排队），而界面文案曾承诺"10–60 秒"；
- 直连单模型实测**中位 97s**，且有**撞满 600s 读超时**的尾部（R 臂 1/12），而关推理臂中位 16.9s、最大 21.9s。

但"更快"不足以决策 —— 必须先确认**判断质量是否退化**。为此设立**预注册的非劣性检验**（见 [E2 预注册](../reviews/2026-09-24-ats-reasoning-eval/E2-preegistration.md)）：
- 两臂唯一差异为 `enable_thinking`；同模型 `qwen3.8-max`、同 prompt、`temperature=0.1`、同输入；
- 非劣性边际 `δ_eff = 8`（满分 100）；单侧 α=0.05；
- 由**独立评分者**按 [E1 rubric](../reviews/2026-09-24-ats-reasoning-eval/E1-rubric.md) **双盲**评分；评分对象为**原始输出**（保留被校验器抹掉的信号）；
- 预注册护栏 K1–K9（契约/接地/注入/耗时/分层/真实锚点/评分可靠性/测量饱和）；
- 预注册**三种互斥结局**：① 非劣通过→关闭；② 实质退化/护栏触发→保留（质量原因）；③ 功效不足或测量无效→保留（证据不足，非质量问题）。

## Decision

**不对 `ATS_ANALYSIS` 关闭推理** —— 不把它加入 `app.ai.bailian.disable-thinking-task-types`。

理由是**多重独立阻断**（不是单一条件兜底）：

| 阻断 | 内容 | 归类 |
| --- | --- | --- |
| **K8（首要认定）** | 两个候选 LLM 副裁判**均未通过 twin 校准** → rubric 可靠性未被证明 | 结局 ③ |
| **K7（待复核红线）** | 唯一的 2 组内容独立真实锚点**双双越线**：`real-6 d=−10`、`real-22 d=−9`，均 `|d| > δ=8` | 列为待复核，**不作质量裁定** |
| **§7.7 δ 敏感度** | δ=8 判非劣、δ=5 判保留 → **三档不一致** → 取保守档 | 预注册规则 |

**K8 为首要认定的依据是「对称性」**：既然认定"尺子可靠性未建立"，则**这把尺子产出的任何数值都不得用于质量结论** —— 该原则**对两个方向同等适用**：
- 主检验的"非劣"（δ=8 下单侧 `p=0.0070`、90% CI 下界 −5.50 > −8）**不能**用来支持关闭；
- K7 的 `−9 / −10` **同样不能**用来支持"质量退化"。

否则会出现自相矛盾：**同一套分数同时被用来证明"工具不可靠"和"质量退化"**。

## Consequences

**正面**
- 避免了在**测量可靠性未经证明**的情况下改变生产行为 —— 这是本轮最重要的一条纪律。
- 产出两个可独立排期的成果（见下）。
- 沉淀了一套可复用的实验纪律与一册决策登记。

**负面 / 未解决**
- **ATS 仍然慢**：直连中位 97s、生产任务级 212–405s，**600s 超时尾部未消除**（本决策不解锁任何提速）。
- **K7 红线未定论**：真实锚点疑似退化 9–10 分，但量具不可靠 → 必须重验，不得据此下结论。
- 本轮**没有取得可执行的结论**，而成本已付出（24 次开推理调用 + 两次失败的裁判全量跑）。

## 为什么答不出问题（本轮最本质的发现）

**不是模型不行，也不是样本数不够** —— 功效门通过（`N_req = 2`、`N_eff = 8`）。真正的原因是**测量分辨率与决策边际不匹配**：

- 两个**内容等价**的真实锚点（`real-6` ≡ `real-11`，`resumeJson`/`jdText` 逐字相同、仅元数据 ID 不同）给出**相差 7 分**的配对差（`−10` vs `−3`）；
- 即**输入层配对差噪声 ≈ 7 分，而 `δ_eff` 只有 8 分** —— **边际与噪声同量级，该量具在此边际下几无分辨力**；
- 叠加另两个问题：评分量表压在 **88–100 近天花板**（K9 虽未触发但已记录近饱和）；**裁判路线在本环境不可行**。

> 因此本轮结局 ③ 的成因应表述为：**工具失效 + 测量分辨率不足**，而**非**"关推理质量更差"。这一区分必须写进任何对外转述。

## 第二轮的必要条件（预注册，三件必须一起做）

1. **两名预注册的独立 agentic 评分者**（互不可见、均不参与 rubric 与 harness 编写；事前登记一致性判据 ρ / pass-fail 一致率 / twin 负对照）；
2. **内容互不相同的真实锚点**（本次真实锚点仅 2 个内容独立样本，且其中一对还是同一内容 → 红线判定缺独立观测）；
3. **重估 `δ` 与量表**（若输入层噪声就在 7 分，`δ=8` 无分辨力 → 需**增样本 + 缩 δ**，或改用更灵敏量表脱离天花板）。

⚠ **不可只换裁判** —— 只修第 1 项会让第二轮重演同样的 ③。
